02

Arsenal de Tyria

Publicado · PWA

Buscador de objetos de Guild Wars 2 con recetas, precios del bazar y datos de la cuenta del jugador, instalable en PC y celular. Nació como una app Android en Kotlin y lo rehice para la web: en vez de descargar el catálogo en cada dispositivo (unas 370 llamadas a la API), un workflow de GitHub Actions genera todos los días un índice estático de ~74.000 objetos y la búsqueda corre localmente en el navegador, incluso sin conexión.

  • TypeScript
  • React
  • Vite
  • PWA
  • REST APIs
  • GitHub Actions
